# Gemini — Project Instructions

See [AGENTS.md](./AGENTS.md) for full project context, structure, commands, and conventions.

## Additional Notes for Gemini

- Prefer editing existing files over creating new ones.
- Do not add comments, docstrings, or type annotations to code you didn't change.
- Do not add error handling for scenarios that cannot happen.
- Do not introduce features, refactoring, or "improvements" beyond what was asked.
- Run `npm run build` after any source changes to verify type-checking passes.
- Run `npm run test:e2e` when changes affect rendering, navigation, zoom, or rotation.
